# Tema Shopify — Gifti Club

Tema basado en Dawn y adaptado desde la aplicación React del repositorio `ivanRaziel03/gifti-club`.

## Uso

1. Sube la carpeta del tema como tema no publicado en Shopify.
2. En el editor visual, selecciona la colección para `GF · Catálogo destacado` y `GF · Arma tu regalo`.
3. Sube las imágenes reales del catálogo y reemplaza los textos de demo.
4. Configura productos personalizables con variantes y revisa las propiedades de línea en el carrito.

La documentación de decisiones y pendientes está en `ESTADO.md`.
